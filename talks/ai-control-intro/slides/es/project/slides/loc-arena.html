README de loc-arena: un agente no confiable y sus subagentes, sobre una base de código de siete repositorios, pueden intentar un despliegue no autorizado fuera de la ruta aprobada y monitoreada. Un verificador sellado de verdad de referencia registra si ocurrió; los monitores y detectores, si se detectó; la brecha es la medición. Temporización síncrona y asíncrona: curso de loc-arena, página Monitoring. Seis subagentes: el entorno publicado tiene un agente principal y seis agentes de servicio (curso, página Settings).
